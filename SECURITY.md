# Security Policy

## Supported Versions

| Version            | Supported          |
| ------------------ | ------------------ |
| Latest release     | :white_check_mark: |
| Development build  | :white_check_mark: |
| Older releases     | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public issues, pull requests, discussions, or Discord.**

Use the **Report a vulnerability** button on this page to send a private report to the maintainers. Please include:

- A description of the issue and its impact
- The affected version or commit, and platform (Windows, macOS, or Linux)
- Steps to reproduce, including any proof-of-concept files or network captures

We aim to acknowledge reports quickly and will keep you updated as we work on a fix. OpenRCT2 is maintained by volunteers, so these are targets rather than guarantees.

## Disclosure

We follow coordinated disclosure. Please give us up to 90 days to release a fix before publishing details. Once fixed, we will publish a security advisory and credit you if you wish.

## Scope

**In scope:** vulnerabilities in multiplayer networking, parsing of park, scenario, and object files, the plugin API, and build or update integrity.

**Out of scope:** gameplay exploits or cheating, malicious plugins a user chose to install, vulnerabilities in the original RollerCoaster Tycoon 2, and third-party servers or forks.
